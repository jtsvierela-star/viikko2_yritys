How this supposed to work?

Counter shows the number of page reloads.
Python counter add number one in every reload. At back end python app will add that to the database.
Python has its own user for updating database. Main objective was about
getting counter up and building services for Ubuntu server.
The idea in services was maintaining server that the website would have survived
server reboot without losing the data. Of course the services supposed to start
automatically. That is done with systemd file. After file configurations are ready
they are reloaded, enabled and started with certain systemctl-command.
